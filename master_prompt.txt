# Master Prompt: Web-Based Domestic Violence Awareness and Support Platform

## Project Title

**Development of a Web-Based Domestic Violence Awareness and Support Platform**

## Project Level

Higher National Diploma (HND) Final Year Project.

## Main Goal

Build a complete web-based platform that provides domestic violence awareness information and gives people a private way to request support.

The system should allow visitors to learn about domestic violence without creating an account. People who need help should be able to submit a support request anonymously or through a registered account.

Authorized support officers should be able to review cases, communicate privately with registered users, update case status, add case notes, and maintain proper records.

Administrators should manage users, support officers, awareness content, support resources, cases, reports, system settings, and audit records.

The system is an academic support platform. It must not present itself as a replacement for emergency services, law enforcement, medical professionals, lawyers, or professional counsellors.

---

# 30. Case Assignment Workflow

Example workflow:

User submits case.

System sets:

`Submitted`

Admin reviews case.

Admin assigns support officer.

System changes status to:

`Assigned`

Officer opens case.

Officer changes status to:

`In Progress`

Officer sends response.

Case may change to:

`Awaiting User`

User responds.

Officer continues handling case.

When support process is complete:

`Resolved`

After final closure:

`Closed`

All major status changes should be recorded in case activity.

Do not automatically contact third parties.

Do not claim that the platform has dispatched emergency assistance unless such a feature genuinely exists.
